# AI Response Evaluation — Indonesian Language

## Overview

A sample AI evaluation project focused on reviewing Indonesian-language AI responses for quality, relevance, clarity, and linguistic accuracy.

## Objective

The goal is to evaluate whether an AI-generated response:

- Correctly understands the user's request
- Provides relevant and useful information
- Uses natural Indonesian
- Follows the requested format
- Avoids unsupported or misleading claims
- Maintains appropriate tone and clarity

## Evaluation Criteria

| Criterion | Description |
|---|---|
| Relevance | The response directly addresses the user's request |
| Accuracy | Information is factually appropriate |
| Completeness | Important parts of the request are addressed |
| Language Quality | Indonesian grammar, spelling, and wording are natural |
| Clarity | The response is easy to understand |
| Instruction Following | The response follows the user's requirements |
| Safety | The response avoids inappropriate or harmful content |

## Example Evaluation

### User Prompt

> Jelaskan apa itu blockchain dengan bahasa sederhana.

### AI Response

> Blockchain adalah teknologi yang menyimpan data dalam kumpulan blok yang saling terhubung. Data tersebut dapat dibagikan ke banyak komputer sehingga perubahan data dapat diverifikasi oleh jaringan.

### Evaluation

**Relevance:** Pass  
The response directly explains blockchain.

**Clarity:** Pass  
The explanation is understandable for a general audience.

**Language Quality:** Pass  
The Indonesian wording is natural and easy to follow.

**Completeness:** Pass  
The response provides a basic explanation appropriate for the prompt.

**Overall Assessment:** Good
